Page

Use {{node.output}} for values, {{#node.list}}...{{/node.list}} to repeat. Values are escaped and the HTML is sanitized: no scripts and no external images (use data: URIs). For a PDF header or footer, give an element position: running(header) and use @page { @top-center { content: element(header) } }; page numbers with counter(page). The PDF supports CSS 2.1 and paged media, not flex or grid.
